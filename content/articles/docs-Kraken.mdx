## Overview

Kraken is a modular line follower robot built with [PlatformIO](https://platformio.org/). It uses an infrared sensor array to detect the line position and a PID controller to continuously adjust motor speeds, keeping the robot centered while predicting the correct direction at line intersections.

The firmware is divided into four independent modules:

- Sensors
- PID Controller
- Motor Control
- Main Application

## Architecture

### Sensors

Responsible for:

- Reading the infrared sensors
- Calculating the line position error
- Detecting line loss
- Providing input to the PID controller

### PID Controller

Responsible for:

- Computing the proportional, integral, and derivative terms
- Generating correction values
- Adjusting left and right motor speeds

Default parameters:

```cpp
Kp = 18.0;
Ki = 0.0;
Kd = 9.0;

baseSpeed = 130;
```

### Motor Control

Responsible for:

- Motor direction control
- PWM speed control
- Differential steering
- Stop routines

---

## PID Logic

```text
integral      = integral + error
derivative    = error - previousError
pid           = (Kp * error) + (Ki * integral) + (Kd * derivative)
previousError = error
```

Motor output:

```text
leftSpeed  = dynamicBase + pid
rightSpeed = dynamicBase - pid
```

This feedback loop enables smooth, real-time line tracking.

## Installation

Clone the repository:

```bash
git clone git@github.com:Matheus-Sounier/Kraken_arduino.git
```

Enter the project directory:

```bash
cd Kraken_arduino
```

Open the project in **Visual Studio Code**. PlatformIO will automatically install the required toolchain and dependencies.

---

## Build

Compile the firmware:

```bash
pio run
```

or use **PlatformIO → Build**.

---

## Upload

Connect the Arduino Uno and upload the firmware:

```bash
pio run --target upload
```
