Kraken is a line follower robot project built with **[Arduino](https://docs.arduino.cc/)** and **[PlatformIO](https://docs.platformio.org/)** using a modular firmware architecture. Infrared sensors detect the line position while a PID controller continuously adjusts the motor speeds to keep the robot centered on the track.

The firmware is organized into independent modules for sensors, PID control, motor control, and the main application, making the project easier to maintain and extend.

---

## Hardware

### Components

- [Arduino Uno R3](https://docs.arduino.cc/hardware/uno-rev3/)
- L298N Dual H-Bridge Driver
- 2× 6V DC Motors
- 2× Wheels
- Infrared Sensor Array
- 9V Power Supply

## Modules

### Sensors

Responsible for:

- Reading the infrared sensors
- Calculating the line position error
- Detecting line loss
- Providing input for the PID controller

---

### PID Controller

Responsible for:

- Proportional (P), Integral (I), and Derivative (D) control
- Computing correction values
- Adjusting left and right motor speeds

Default parameters:

```cpp
Kp = 18.0;
Ki = 0.0;
Kd = 9.0;

baseSpeed = 130;
```

---

### Motor Control

Responsible for:

- Motor direction control
- PWM speed control
- Stop routines
- Differential steering

---

## PID Logic

The controller continuously computes the PID output:

```text
integral      = integral + error;
derivative    = error - previousError;
pid           = (Kp * error) + (Ki * integral) + (Kd * derivative);
previousError = error;
```

Motor speeds are adjusted dynamically:

```text
leftSpeed  = dynamicBase + pid;
rightSpeed = dynamicBase - pid;
```

This enables smooth steering corrections while following the line.

## Installation

Clone the repository:

```bash
git clone git@github.com:Matheus-Sounier/Kraken_arduino.git
```

Enter the project directory:

```bash
cd Kraken_arduino
```

Open the project in **[Visual Studio Code](https://code.visualstudio.com/)**.

**[PlatformIO](https://docs.platformio.org/)** will automatically download:

- AVR toolchain
- Arduino framework
- Required packages

---

## Build

Compile the firmware:

```bash
pio run
```

Or use **PlatformIO → Build** inside Visual Studio Code.

---

## Upload

Connect the **[Arduino Uno R3](https://docs.arduino.cc/hardware/uno-rev3/)** and upload the firmware:

```bash
pio run --target upload
```
