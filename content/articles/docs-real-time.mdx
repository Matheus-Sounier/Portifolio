A real-time motion-controlled system built with **C++**, **OpenCV**, and **CMake**.

This project allows players to control keyboard inputs using body movement detected through a webcam. Instead of relying on traditional peripherals, the system detects motion inside configurable regions and automatically presses the assigned keys.

---

## Features

- Real-time motion detection using a webcam
- Customizable motion detection areas (ROIs)
- Keyboard binding for each detection area
- Persistent square configuration
- Optional jump detection system
- Jump power measurement based on airtime
- Motion-based directional controls
- Built with OpenCV and modern C++

## How It Works

The system continuously captures frames from a webcam using **OpenCV**.

Each frame is compared with the previous one to detect movement inside predefined **Regions of Interest (ROIs)**.

When motion exceeds a configurable threshold inside an ROI, the corresponding keyboard key is automatically triggered.

---

### Detection Squares

Detection squares (ROIs) can be placed anywhere on the camera feed.

Each square acts as an independent motion sensor.

Whenever movement is detected inside a square, the assigned keyboard key is pressed automatically.

```text
Motion Detected
      ↓
ROI Activated
      ↓
Keyboard Key Pressed
```

This allows players to create custom control layouts for different games.

---

### Jump Detection

When enabled, a horizontal line appears on the screen.

The system monitors movement above this line.

If the player crosses the line, the jump detection algorithm starts measuring the airtime.

The duration of the jump can then be used to determine jump strength or trigger different in-game actions.

```text
Player Crosses Line
        ↓
Jump Starts
        ↓
Airtime Measured
        ↓
Jump Ends
```

---

## Detection Method

The project uses **frame differencing**, a common computer vision technique for motion detection.

The process consists of:

1. Capturing consecutive webcam frames.
2. Converting frames to grayscale.
3. Computing the absolute difference between frames.
4. Applying a threshold to isolate moving pixels.
5. Measuring the amount of motion inside each ROI.
6. Triggering keyboard events when the configured threshold is exceeded.

This approach is lightweight, fast, and suitable for real-time applications.

## Installation

Clone the repository:

```bash
git clone git@github.com:Matheus-Sounier/Real-Time-Motion.git
```

Enter the project directory:

```bash
cd Real-Time-Motion
```

Create a build directory:

```bash
mkdir build
```

Generate build files:

```bash
cmake -B build/
```

Build the project:

```bash
cmake --build build/
```

---

## Running

After building, the executable will be generated inside the build folder.

Example:

```text
D:\Projects\YourProjectDirectory\build\Debug\JumpKingIRL.exe
```

Run the executable from the terminal.

HOW TO BIND A KEY:

- Press a key to bind it to the selected square.

HOW TO MOVE A SQUARE:
- Click on a square to select it.
- Use the arrow keys to move the square within the window.

HOW TO REMOVE A SQUARE:
- Click on a square to select it.
