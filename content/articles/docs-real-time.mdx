A real-time motion-controlled system built with **C++**, **OpenCV**, and **CMake**.

The project allows players to control keyboard inputs using body movement detected through a webcam. Motion inside configurable regions automatically triggers the assigned keyboard keys.

---

## Features

- Real-time motion detection using a webcam
- Configurable motion detection areas (ROIs)
- Custom keyboard bindings
- Persistent square configuration
- Optional jump detection
- Jump power measurement based on airtime
- Motion-based directional controls

## How It Works

The application captures webcam frames with **OpenCV** and compares consecutive frames to detect movement inside predefined **Regions of Interest (ROIs)**.

When movement exceeds a configurable threshold, the corresponding keyboard input is automatically triggered.

---

### Detection Squares

Each ROI acts as an independent motion sensor that can be positioned anywhere on the camera feed.

```text
Motion Detected
      ↓
ROI Activated
      ↓
Keyboard Key Pressed
```

---

### Jump Detection

When enabled, the system monitors movement above a configurable horizontal line. Crossing the line starts airtime measurement, which can be used to determine jump strength or trigger different in-game actions.

```text
Player Crosses Line
        ↓
Jump Starts
        ↓
Airtime Measured
        ↓
Jump Ends
```

---

## Detection Method

Motion detection is based on **frame differencing**:

1. Capture consecutive frames.
2. Convert to grayscale.
3. Compute the absolute difference.
4. Apply a threshold.
5. Measure motion inside each ROI.
6. Trigger keyboard events when the threshold is exceeded.

This lightweight approach is well suited for real-time applications.

## Requirements

Install:

- **Visual Studio** (Desktop Development with C++)
- **CMake**
- **OpenCV**

Ensure both **CMake** and **OpenCV** are correctly configured in your system environment.

---

## Installation

```bash
git clone git@github.com:Matheus-Sounier/Real-Time-Motion.git
cd Real-Time-Motion

cmake -B build
cmake --build build
```

---

## Running

After building, the executable will be generated inside the `build` directory.

Example:

```text
D:\Projects\YourProjectDirectory\build\Debug\JumpKingIRL.exe
```
