A real-time facial recognition access control system built with [Python](https://docs.python.org/3/), [MediaPipe](https://ai.google.dev/edge/mediapipe), [InsightFace](https://github.com/deepinsight/insightface), [FastAPI](https://fastapi.tiangolo.com/), and [Streamlit](https://docs.streamlit.io/). Facial embeddings are stored in an [Oracle Database](https://www.oracle.com/database/) running inside [Docker](https://docs.docker.com/).

The project also includes LLM-powered analytics through [OpenRouter](https://openrouter.ai/docs/), enabling natural-language SQL queries and automatic descriptions of unrecognized faces.

## Architecture

The system is composed of four main components:

- **Desktop Application** — captures frames from the webcam and performs face detection.
- **FastAPI** — enrollment, recognition, logging, and analytics endpoints.
- **Oracle Database** — stores facial embeddings and access logs.
- **Streamlit Dashboard** — visualizes access history and AI-generated analytics.

## Installation

Clone the repository:

```bash
git clone git@github.com:Matheus-Sounier/Face-Access-Control-System.git

cd Face-Access-Control-System
```

Copy the environment file:

```bash
cp .env.example .env
```

Download the MediaPipe model:

```bash
mkdir -p models

curl -o models/blaze_face_full_range.tflite \
https://storage.googleapis.com/mediapipe-models/face_detector/blaze_face_full_range/float16/1/blaze_face_full_range.tflite
```

## Oracle Database

Access the Oracle container:

```bash
docker exec -it -u oracle oracle_face_detection sqlplus / as sysdba
```

Switch to the pluggable database:

```sql
ALTER SESSION SET CONTAINER = FREEPDB1;
```

Create the application user:

```sql
CREATE USER your_app_user IDENTIFIED BY your_password;

GRANT CONNECT, RESOURCE TO your_app_user;
GRANT UNLIMITED TABLESPACE TO your_app_user;
```

(Optional) Create a read-only user for the analytics endpoint:

```sql
GRANT CREATE SESSION TO analytics_user;

GRANT SELECT ON your_app_user.DETECTED_PEOPLE TO analytics_user;
GRANT SELECT ON your_app_user.ACCESS_LOGS TO analytics_user;

CREATE SYNONYM analytics_user.DETECTED_PEOPLE
FOR your_app_user.DETECTED_PEOPLE;

CREATE SYNONYM analytics_user.ACCESS_LOGS
FOR your_app_user.ACCESS_LOGS;
```

## Running

Start the backend services:

```bash
docker compose up -d --build
```

Run the desktop application:

```bash
python -m venv .venv

pip install -r requirements-desktop.txt

python main.py
```

## Usage

### Enroll

```bash
curl -X POST http://localhost:8000/enroll \
  -F "name=elon" \
  -F "employee_id=0099" \
  -F "access_level=Employee" \
  -F "photo_1=@photo1.png"
```

Additional photos improve recognition accuracy.

---

### Recognize

```bash
curl -X POST http://localhost:8000/recognize \
  -F "file=@photo.png"
```
