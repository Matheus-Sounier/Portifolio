Training can be resumed from the last checkpoint generated by **[Ultralytics YOLO](https://docs.ultralytics.com/)**.

```python
from ultralytics import YOLO

model = YOLO(
    "runs/detect/license_plate_training/weights/last.pt"
)

results = model.train(
    resume=True
)
```

---

## Continue Training

To continue training for additional epochs, load the previously trained model and specify a new number of epochs.

```python
from ultralytics import YOLO

model = YOLO(
    "runs/detect/license_plate_training/weights/best.pt"
)

results = model.train(
    data="dataset/data.yaml",
    epochs=100,
    project="license_plate",
    name="license_plate_100epochs"
)
```

---

# Model Notes

- Trained to detect **Mercosur** license plates.
- Performance depends on image quality, lighting, and camera distance.
- Higher epoch counts do not necessarily improve accuracy.
- Monitor **mAP50-95** and validation loss to avoid overfitting.
- Use `best.pt` for inference whenever possible.

# Common Issues

## Model not found

```text
FileNotFoundError:
No such file or directory
```

Verify that the model path is correct.

```bash
ls runs/detect/
```

---

## CUDA unavailable

```text
Torch not compiled with CUDA enabled
```

Verify that **[PyTorch](https://pytorch.org/docs/stable/)** detects your GPU.

```python
import torch

print(torch.cuda.is_available())
```

---

## Oracle connection error

```text
ORA-12514
ORA-12154
```

Verify your **[Oracle Database](https://www.oracle.com/database/)** connection settings:

- Host
- Port
- Service Name
- Username
- Password

---

## Low video processing performance

Possible causes include:

- High-resolution video input
- Large **[YOLO](https://docs.ultralytics.com/)** model
- OCR processing overhead
- CPU inference instead of GPU inference
